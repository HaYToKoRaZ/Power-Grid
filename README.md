# Websites Dizin Bilgisi

Bu klasör, **SwitchPowerScheme** masaüstü uygulamasının geliştirilmesi tamamlandıktan sonra oluşturulacak olan resmi tanıtım ve indirme web sitesinin (landing page) kaynak kodları için ayrılmıştır.

Şu an için boştur; yazılım geliştirme süreci bittiğinde web sitesi burada inşa edilecektir.
